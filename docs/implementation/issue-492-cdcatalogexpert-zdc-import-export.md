# Issue #492: Add CD Catalog Expert 9.x ZDC import/export plugin

## Summary

Extended the native CD Catalog Expert 9.x plugin (#490) from an opaque
container mapping to a real import/export of the stored catalog hierarchy.
The plugin keeps format id `cd-catalog-expert-zdc` and is implemented through
the existing capability interfaces (`IFileFormatPluginCapability`,
`IContentAwareFileFormatCapability`); identity still comes from assembly
metadata with no `plugin.json`.

## New grammar layer: `Plugins/SkyCD.Plugin.CdCatalogExpert`

- `ZdcCatalogModel` — catalog, groups, discs, disc trees, and tree entries.
  Raw legacy values stay as their original invariant text; unknown attributes
  are kept as ordered extension pairs.
- `ZdcCatalogXmlReader` — strict Windows-1252 reader for `zdc_index.xml` and
  disc-tree members. Undefined Windows-1252 bytes are rejected explicitly.
  `XmlReader` is hardened (`DtdProcessing.Prohibit`, no resolver,
  `CheckCharacters`) and bounded by depth/element/attribute/text/document
  limits, with periodic cancellation checks. Allowed attribute sets per
  element are enforced; duplicate attributes, invalid signed numbers, scan
  flags, GUIDs, and file sizes are rejected with the member and field named.
  Unknown elements are skipped with a warning instead of failing.
- `ZdcCatalogXmlWriter` — validates every value (Windows-1252
  representability, XML character validity, numeric ranges, required names,
  size formats) before writing, then emits the index and disc trees in the
  profile's element/attribute grammar. Only non-empty optional attributes are
  written, and file sizes default to `0`.
- `ZdcCatalogParser` — resolves disc-tree members referenced from the index
  (GUID, bare, and braced candidate names, case-insensitive), reports missing
  covers as warnings, and fails on missing/duplicate tree references.
- `ZdcCatalogMapper` — converts between `ZdcCatalog` and the shared flat
  node rows, and between rows and a `ZdcDatabase`. Row `properties` carry the
  catalog, group, disc, and tree-entry metadata listed in the plugin guide.
  The writer rebuilds groups/discs from `ZdcNodeKind`, rolls stray
  file/folder rows into a synthesized disc, and derives deterministic disc
  GUIDs from catalog/disc identity so repeated saves are byte-stable.
- `ZdcPlugin` — read path: `ZdcReader` → `ZdcCatalogParser` →
  `ZdcCatalogMapper.BuildRows`; write path: rows → `ZdcCatalogMapper.ToDatabase`
  → `ZdcWriter`. The previous structural `ZdcReportBuilder` was removed.
- Custom exceptions (one per file): `ZdcFormatException`,
  `ZdcCharacterNotRepresentableException`.
- No new NuGet dependencies (BCL only); license policy unaffected.

## Fixtures

Checked-in synthetic fixtures generated by the plugin writer (no genuine CD
Catalog Expert files are redistributed):

- `minimal.zdc` — catalog/group/disc with an empty tree.
- `full.zdc` — nested groups, metacharacters, CR/LF, Windows-1252 text, every
  disc field, cover, unknown attribute, `ulong.MaxValue` size.
- `boundary.zdc` — 160 KB of tree data across multiple chunks.
- `sample.zdc` + `sample.manifest.json` — pinned member manifest and
  decompressed payload hashes.
- `malformed/*.zdc` — missing tree member, bad GUID, invalid number, invalid
  encoding, malformed XML, excessive depth, corrupt container.

Each well-formed fixture has a `.expected.json` describing the expected
catalog name, media fields, files, directory count, member hashes, and
warnings.

## Tests (`tests/SkyCD.Plugin.CdCatalogExpert.Tests`)

- Grammar tests: raw value preservation, escaping and line endings,
  non-representable/control characters, unknown attributes and elements,
  invalid number/flag/GUID/size, missing names/size, DTD prohibition,
  depth bound, Windows-1252 decoding (including undefined bytes), empty
  directories, `ulong.MaxValue` sizes, cancellation, missing cover warnings,
  duplicate tree references.
- Reader tests: catalog hierarchy row shape, raw disc field preservation,
  tree fields and cover, content sniffing (including non-`.zdc` extension),
  non-seekable streams, missing member failures.
- Writer tests: canonical member order, index synthesis, fresh rows, plugin
  read/write row-for-row round trip (identity, kind, name, size, properties),
  byte-identical repeated saves, non-representable character failure,
  invalid payload failure.
- Checked-in fixture tests: manifest/hash verification, byte-identical
  rewrite, per-fixture expectations, malformed containers, corrupt container.
- All tests pass (executed via a reflection runner; `dotnet test` testhost is
  denied in this environment — the same environmental failure as #490).
