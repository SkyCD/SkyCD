# Where Is It? XML report import plugin (`whereisit-xml-report`)

Read-only capability in `SkyCD.Plugin.WhereIsIt` that imports Where Is It?
"List of all cataloged files and folders on selected disks" XML exports.
The mapping follows the Librer reference implementation
(`info/wii_import.md`, `src/core.py`), including its tolerant behaviors:
first-wins fields, multi-line descriptions, CDATA markers stripped, bad sizes
kept as zero, and unregistered-version `*** DEMO ***` placeholders skipped
instead of partially published.

## File shape

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!-- Generated by WhereIsIt Report Generator 3.93 -->
<REPORT Title="Home Archive">
  <ITEM ItemType="File">
    <NAME>readme</NAME>
    <EXT>txt</EXT>
    <SIZE>512</SIZE>
    <DATE>2024-02-06</DATE>
    <TIME>11:31:00</TIME>
    <DISK_NAME>Backup</DISK_NAME>
    <DISK_TYPE>Hard disk</DISK_TYPE>
    <DISK_NUM>1</DISK_NUM>
    <DISK_LOCATION>Office</DISK_LOCATION>
    <PATH>\Documents\</PATH>
    <CRC>305441741</CRC>
    <CATEGORY>Work</CATEGORY>
    <FLAG>Archive</FLAG>
    <DESCRIPTION><![CDATA[read me]]></DESCRIPTION>
  </ITEM>
  ...
</REPORT>
```

`ITEM` entries carry `ItemType="File"` or `"Folder"`; anything else is skipped
with a reason, and `ItemType="Disk"` aborts the import as an incompatible kind
(no partial catalog is ever published). Required fields are disk name, path,
name and a non-demo extension; missing or demo-polluted entries are skipped
with counted notes. Nested `ITEM` elements are rejected as malformed.

## Imported data

Each distinct `DISK_NAME` becomes a media entry, preserving disk metadata
(type, number, location). Backslash paths build the folder hierarchy
(intermediate folders are synthesized); file names append the extension when
present. Sizes are unsigned (`>4 GiB` works); dates keep their raw display form
plus ISO normalizations. Descriptions survive multi-line content; CRC stays
verbatim; category, flag and the original path travel as properties. Unknown
elements and attributes are retained as `WhereIsIt.<name>` extension metadata
and reported once. Demo-only reports import as nothing and fail as empty.

Repeated imports of several reports merge naturally: volumes share stable
`volume:{disk}` ids, so importing another report for the same disk enriches it
instead of duplicating it.

## Safety bounds

Parsing uses hardened `XmlReader` settings (no DTD, no resolvers), a 256-level
depth cap, a 1,000,000-item cap and a 256 MiB document cap, with cancellation
honored while reading. DTD/XXE content is rejected; malformed nesting, invalid
numbers, unknown item kinds and disk-level reports fail with typed diagnostics.

## Tests

`tests/SkyCD.Plugin.WhereIsIt.Tests` covers a complete two-disk fixture
(hierarchy, counts, sizes, timestamps, metadata, duplicates in distinct paths,
demo and unknown-type skips, unknown-field retention), missing fields, bad
values, disk-kind/empty/malformed/wrong-root failures, recognition (including
Disk Explorer disambiguation and stream-position preservation) and cancellation.
