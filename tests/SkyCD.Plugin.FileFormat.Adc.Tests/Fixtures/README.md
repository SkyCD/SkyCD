# Advanced Disk Catalog fixtures

These files are synthetic, license-safe Advanced Disk Catalog databases generated by
`AdcFixtureWriter` from the catalogs in `AdcFixtures`. They are not produced by ElcomSoft
software and contain no third-party data.

`manifest.json` is the import oracle: for every fixture it lists the expected volumes,
entries, paths, kinds, sizes, timestamps, comments, categories, attributes, type codes and
preserved properties. The integration tests read the committed bytes and compare the plugin
output against the manifest instead of recomputing expectations.

| File | Purpose |
| --- | --- |
| `empty.cat` | Catalog with no volumes, items, categories or comments. |
| `nested.cat` | Nested folders, an empty folder, timestamps, and typed/item extension properties. |
| `multivolume.cat` | Multiple volumes with Unicode labels, a category, and a file larger than 4 GiB. |
| `comments.cat` | Comments, multiple categories, and duplicate basenames under different parents. |
| `malformed/truncated.cat` | Header truncated before the documented size. |
| `malformed/corrupt.cat` | Damaged `ADC.Catalog` signature. |
| `malformed/unsupported.cat` | Unsupported major format version. |
| `windows-security.cat` | Windows Authenticode security catalog (`.cat` extension collision), which must be rejected. |

To regenerate the files after changing the writer or the sample catalogs, run the tests with
`SKYCD_REGENERATE_ADC_FIXTURES=1`; `AdcFixtureConsistencyTests` verifies the committed bytes
match the generator.
