# DiskCatalogMaker v5 catalog fixtures

These files are synthetic DiskCatalogMaker v5 payloads authored for this repository
and distributed under its license. They were generated by
`DiskCatalogMakerV5Fixtures` in the test project; no DiskCatalogMaker application
binary, sample catalog, or third-party data is redistributed.

## Provenance

The issue describes DiskCatalogMaker's columnar storage model (`TDCatalogFileV5*`,
`TDVolume*TableV5`), a `Catalog.dcm` payload inside `.dcmd` packages, a
`Thumbnails/aa/bb/cc/dd.ext` object store, and defensive table/offset validation,
but no public byte-level sample or specification was available. The committed
fixtures therefore follow the layout implemented by this plugin and documented in
`docs/plugins/diskcatalogmaker-v5.md`. They prove parser and hierarchy behavior,
not interoperability with a specific vendor build.

## Fixtures

| File | Purpose |
| --- | --- |
| `empty.dcmf` | Header with no tables, volumes or items. |
| `single-volume-unicode.dcmf` | Nested Unicode folders, zero-byte and 5 TB files, type/creator codes, comments, labels, POSIX modes and dates. |
| `multiple-volumes.dcmf` | Two volumes with duplicate `readme.txt` names under distinct parents. |
| `aliases.dcmf` | Alias/original-item fields including mount point, server, Unicode names and recursive extra bytes. |
| `unknown-table.dcmf` | Unknown table `0x0100` preserved as opaque bytes with a warning. |
| `package-with-thumbnails/Catalog.dcm` | Package payload with a thumbnail reference and matching object. |
| `package-with-thumbnails/Thumbnails/0a/0b/0c/0d.png` | Minimal valid PNG object for key `0x0A0B0C0D`. |
| `package-without-thumbnails/Catalog.dcm` | Same package payload without the optional object store. |
| `corrupt-truncated-header.dcmf` | Payload shorter than the documented header. |
| `corrupt-truncated-table.dcmf` | Table directory references bytes beyond the payload. |
| `corrupt-invalid-count.dcmf` | Record count above the supported maximum. |
| `corrupt-invalid-offset.dcmf` | Table offset beyond the payload. |
| `corrupt-overlap.dcmf` | Two table ranges overlapping. |
| `unsupported-version.dcmf` | Header major version 6. |

To regenerate the files after changing the fixture generator or the documented
layout, run the tests with `SKYCD_REGENERATE_DCM5_FIXTURES=1`.
`DiskCatalogMakerV5FixtureConsistencyTests` verifies the committed bytes match the
generator.
