# CD Catalog Expert fixtures

`sample.zdc` is a small redistributable CD Catalog Expert 9.x container
generated by the plugin writer itself (`ZdcWriter`) from the synthetic catalog
in `ZdcFixture.SampleDatabase`: the catalog index, two disc XML members, and
one disc cover. No genuine CD Catalog Expert files are redistributed.
`sample.manifest.json` pins the expected member manifest (names, stored
lengths, decompressed payload sizes) and the SHA-256 of every decompressed
payload plus the whole container.

The fixture — not CD Catalog Expert — is the compatibility oracle for normal
development and CI: `ZdcCheckedInFixtureTests` reads it back, compares the
member manifest and payload hashes against the manifest file, and asserts the
container rewrites byte-identically.

Runtime-built fixtures (`ZdcFixture`) cover the rest: header offsets, record
types, checksum/CRC vectors, cross-chunk and multi-index-chain payloads,
multiple directory chunks, empty members, deterministic output, and every
specified negative case. Malformed inputs are produced by byte-level mutation
of valid archives.
